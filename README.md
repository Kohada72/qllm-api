# QLLM Experiment Control System (開発中)

量子計算（Quantum Neural Networks）を組み込んだ大規模言語モデル（LLM）の学習実験を管理・可視化するためのアプリケーションです．

## 目的

本アプリケーションは，量子ニューラルネットワークを導入したLLMのファインチューニングを実行・管理する目的で制作されました．量子回路のパラメータを含む，学習に必要なハイパーパラメータを指定し，ジョブを発行することで，バックグラウンドで非同期にジョブが実行されます．発行すると一覧から情報を参照でき，実行が完了するとPerplexityなどのメトリックと学習曲線を表示・ダウンロードすることができます．

### 実装が完了している機能

1. ジョブの発行とバックグラウンドでの実行．
2. 結果の記録・グラフの生成．

### 今後のロードマップ

1. Server-Sent Events + フロントエンドフレームワーク移行による，リロードなしでの進捗表示．
2. ユーザ概念の導入，PostgreSQL等による独立したサーバでのDB管理．
3. Redis + Celeryによるジョブの独立した管理．

> [!NOTE]  
> **コアロジックについて** > バックエンドの量子計算（QLLM）エンジンおよび学習処理の実装は，研究の事情により本リポジトリでは**モック（ダミーロジック）**に差し替えられています．

## 技術選定理由

* **Frontend: Streamlit**
  * 慣れたPythonによる記述や簡易的に構築できる点から，UI開発のコストを最小限に抑え，バックエンドのイテレーションとロジックの検証に集中する目的で選定した．将来的なReact等への移行を見据えた「足場」として採用．
* **Backend: FastAPI (Python 3.12)**
  * 高速な型検証（Pydantic）による堅牢なAPI設計と，長時間の学習ジョブを制御するための `BackgroundTasks`（非同期処理）を標準でサポートしているため．
* **Database: SQLite**
  * 単一ファイルで動作するため環境構築の手間がなく，プロトタイプ期におけるデータモデルの頻繁な変更に柔軟に対応するため．
* **Container: Docker / Docker Compose**
  * 大学の共有GPUサーバなど，異なるホスト環境へデプロイする際のコストを削減し，手元での開発と実用を高速で行き来できるようにするため．
* **Package Management: Poetry**
  * 機械学習系ライブラリや量子計算ライブラリはバージョン依存が激しいため，決定論的なビルド（`poetry.lock`）によって複数環境間での完全な再現性を担保するため．
